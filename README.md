# ARCANA · 月隐塔罗

由 Rayner 分享的手机塔罗网页，支持简体中文、繁體中文与 English。

## 在线体验

https://rayer-jeffrey-lee.github.io/arcana-tarot/

打开网页即可使用，无需注册账号。

## 功能

- 完整 78 张经典 Rider–Waite–Smith 牌面。
- 每日一牌、时间之流、圣三角、四元素四牌、二选一五牌。
- 正位与逆位翻牌、三语解读、关键词、生活／情感／事业提示。
- 魔法氛围音乐、复制解读、保存海报、添加到手机主屏幕。

仅供娱乐与自我反思。网络速度因地区和运营商而异，不能保证所有中国大陆线路稳定访问。

## 关于发布文件

本仓库保存可直接运行的静态网页，GitHub Pages 使用 main 分支根目录发布。应用资源随站点部署，无需图片或字体外部 CDN。

`html2canvas-LICENSE.txt` 是海报工具 html2canvas 的第三方 MIT 许可证，并不自动许可本项目其余代码或 Rayner 的头像。牌画来源与署名见 [credits.html](./credits.html) 和 [assets/cards/ATTRIBUTION.json](./assets/cards/ATTRIBUTION.json)。
